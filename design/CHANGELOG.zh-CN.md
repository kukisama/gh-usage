# 更新日志

[English](../CHANGELOG.md) | 简体中文

这里记录 **gh-usage** 每个版本的重要变化，站在你的角度讲清楚：有什么新功能、哪里变好了、对你有什么用。

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.2.4] — 2026-09-26

更完整地统计大型多代理任务用量，并支持一条命令生成和打开报告。

### 新增

- **一条命令生成并查看报告。** `gh-usage --view`（简写 `-v`，也兼容首参数 `-view`）生成最新 HTML 后，通过 Windows、macOS、Linux 的默认处理程序打开，无需等待按键。支持筛选、自定义 HTML 路径、标准输出导出和 `--merge`；启动失败时提示已保存的文件位置。原有仅导出行为保持不变。

### 修复

- **VS Code 长任务及中断任务不再漏掉已记录用量。** 重放会话快照和增量更新，读取独立的 `copilotCredits`，不再依赖最终费用文案。累计值已包含子任务，因此不会再叠加子任务费用或重复快照。
- **兼容不同版本的完整费用与精度。** 核对累计值和最终结果总额，允许文案四舍五入误差；若上下文控件仅保留部分用量，则保留更完整的最终结果。兼容旧版单数 `1 credit`，来源链接指向实际采用的计费值所在行。
- **回退或重试不再抹掉已经产生的费用。** 按稳定用户请求保留用量，并将不再出现在当前对话中的已计费交流标为「历史轮次」。无关工具文本也不会阻断计费字段解析。

### 变更

- **报告只展示到用户交流轮次。** 每行包含该轮日志记录的子任务用量，CLI 同轮的多模型汇总在页面合为一行，旧版仅有会话总额的记录明确标为「会话汇总」。不再将工具、MCP 或子代理显示为独立计费行。

### 修复

- **Winget 提交预检更可靠。** 发布脚本现在会验证 GitHub CLI 与 WingetCreate 令牌，仅在 GitHub 明确要求组织授权时识别并安全打开经过校验的 GitHub 授权链接，同时检查仓库访问权限、更新过旧工具，并在提交前安全同步落后的个人 `winget-pkgs` 分叉，不会强制重置或覆盖个人提交。

## [1.2.3] — 2026-08-06

### 新增

- **可选美元/人民币费用估算。** 报告可按 GitHub 官方的 `1 credit = 0.01 美元` 换算，并允许编辑美元兑人民币汇率；默认值为 `6.75`，参考日期为 `2026-08-06`。费用显示默认关闭，同时提供 GitHub 账单、官方说明和 UsagePricing 的直达链接。
- **快捷日期范围。** 可选择近 7 天、30 天、3 个月或全部（默认），同时保留自定义起止日期。

### 修复

- **每日机器堆叠柱状图会跟随日期范围。** 快捷范围和自定义日期现在会与报告其他区域一起更新每日图表。
- **VS Code 会话快照不再重复记账。** 扫描器会按稳定的响应 ID 只保留最新持久化状态，避免 JSONL 重写导致 credits 和轮次虚增；多机 CSV 合并时也会继续对相同记录去重。
- **Copilot CLI 会话现在会出现在报告中。** 扫描器以每个会话的 `events.jsonl` 作为可追溯主记录，以 `workspace.yaml.name` 作为权威标题（缺失时回退首条真实用户消息），并由 `workspace.yaml.cwd` 提供项目；只有 SQLite 用量行成功匹配 JSONL 响应后，才用 `session-store.db` 补充精确的 nano-AIU credits、耗时和轮次字段。
- **正在进行和旧版 CLI 会话都能覆盖。** 当前用量由 SQLite（包括实时 WAL）补充；用量表中完全不存在的旧会话，则从非零 `session.shutdown` 指标补漏，并按会话避免重复计费。
- **CLI 来源可精确打开到对应事件。** 每条关联记录都指向真实的 `events.jsonl` 响应行，报告中的「打开」会在 VS Code 中跳到该行，而不是打开 SQLite 数据库。

### 变更

- **默认启用 Copilot CLI 扫描。** 普通执行 `gh-usage` 会自动合并 VS Code 与 CLI 用量；只有明确需要纯 VS Code 报告时才使用 `--no-cli-logs`。旧的 `--include-cli-logs` 参数仍保留兼容。

## [1.2.2] — 2026-06-17

一个补充修复，终于让自动化安装器不再卡住。

### 修复

- **包校验沙箱不再卡住。** 1.2.1 的修复依赖判断控制台是否为交互式，但在 winget 的安装校验沙箱里，控制台仍然被识别为真实终端，于是程序照样等待按键直至超时。现在「按任意键」的暂停只在你真正从资源管理器双击 `gh-usage.exe` 时才触发；终端、CI、包校验运行都会写完报告文件后干净退出。双击运行时 HTML 报告还会自动打开，无需按键即可查看。

## [1.2.1] — 2026-06-16

一个小修复，让程序在没人盯着时也能乖乖收尾。

### 修复

- **非交互环境下不再卡住。** 当没有真实控制台时——比如在 CI、通过管道运行，或在自动化的包校验沙箱里——程序不再等待按键，也不会尝试打开浏览器，而是写完报告文件后干净退出。双击运行和终端运行依旧保留你熟悉的「按任意键打开报告」提示。

## [1.2.0] — 2026-06-14

把报告打磨得能放心分享给任何人。

### 新增

- **一键整页截图。** 报告里新增了相机按钮，点一下就能把整页存成一张小巧的图片（约 430 KB）——发群、贴文档、发进度，都不用再折腾截图工具。
- **一键隐私遮蔽。** 新增隐私开关，点一下就能把主机名、项目名、会话标题全部打码，分享时不怕泄露敏感信息。截图时还会自动开启，再也不怕手滑泄密。

### 优化

- **体积更小，更新更快。** 程序大幅瘦身（Windows 版本约小了 45%），装起来、升级起来都更轻快。
- **截图更清晰、更靠谱。** 截图改用浏览器自身来渲染，打码字段的样子和你在屏幕上看到的一模一样。

## [1.1.0] — 2026-06-05

让冰冷的数字，变成一份你真正愿意打开的报告。

### 新增

- **自包含 HTML 报告。** 每次运行都会生成一个精美的单文件 HTML，任意浏览器双击即看——不用服务器、不用数据库、不用联网。里面有核心指标、每日用量图表、模型分布，还有能搜索、能排序、能翻页的明细记录表。
- **多语言界面。** 报告内置中英文，在页面上一键切换。
- **多机合并。** 在多台电脑上各跑一次 `gh-usage`，把 CSV 收进一个文件夹，用 `--merge` 就能合并成一份带「按机器对比」的汇总报告——团队复盘、换设备都很顺手。

### 优化

- 记录提取更准确，并修复了若干稳定性问题。

## [1.0.0] — 2026-05-18

第一个稳定版本——快、纯本地、直击要点。

### 新增

- **本地用量扫描。** 让 `gh-usage` 扫一遍你的电脑，它就会从本机已有的文件里整理出 GitHub Copilot 使用记录——全程不上传。
- **导出即可进表格。** 结果能导出成 CSV（默认带 UTF-8 BOM，Excel 打开不乱码），也能导出 JSON 接自动化。
- **终端即时摘要。** 每次运行都会在终端打印一段紧凑摘要——总 credits、活跃天数、记录条数、日均用量，一眼看完。
- **Windows 装起来很省事。** 通过 Windows 包管理器一行搞定：`winget install gh-usage`。
